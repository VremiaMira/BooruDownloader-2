BOORU DOWNLOADER — ПЕРВЫЙ ТЕСТ ПОИСКА

1) Распакуй всю папку в удобное место.
2) Запусти «Запуск.bat» двойным щелчком.
3) Выбери сайт цифрой.
4) Нажми Enter для тестового автора или введи свой тег.
5) Пришли мне весь текст результата или файл Logs\search.log.

Новые сайты:
- Blep.art — тестовый автор distortionai.
- Floofgens.net — тестовый автор underscore_abby.
- Оба используют GET /posts.json и требуют непустой описательный User-Agent.
- У обоих лимит API — максимум 2 запроса в секунду; скрипт делает один поисковый запрос за запуск.

ВАЖНО:
- Это первый этап: только поиск, ничего не скачивается.
- Результат и небольшой CSV-пример сохраняются в Archive\<сайт>\<тег>\.
- Настройки доступа находятся в config.ini. Не отправляй мне файл config.ini, если вписал туда реальные ключи или пароли.
- Gelbooru может требовать UserId и ApiKey.
- Blep.art и Floofgens.net добавлены по официальной API-документации, но пока не подтверждены запуском на твоём ПК.
- TBIB пока использует совместимый DAPI-адаптер как проверяемую гипотезу.
- Nozomi использует отдельный бинарный индекс; показанное число предварительное и должно быть сверено с сайтом.
- После проверки поиска добавим полноценную загрузку, проверки файлов, пропуск уже скачанных, повторы, CSV и журнал ошибок из исходного скрипта.
